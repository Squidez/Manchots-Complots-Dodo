# Manchots-Complots-Dodo
## Description
*Manchots, Complots, Dodo* est une fiction interactive réalisé avec twine pour le cours de *Fiction Interactive* donné par Isaac Pante à l'Université de Lausanne.

Le jeu vise à explorer le phénomène de *Chatbot Psychosis* qui pousse des utilisateur/ices de *chatbot* à développer des comportements psychotiques. Le jeu vous propose d'incarner une IA et de proposer des réponses à Fred, une personne présentant des signes de paranoïa et dépression.

## Utilisation
Le jeu à été réalisé sur Twine. Il peut être lancé et modifié en executant le fichier `manchots-complots-dodo.twee` avec le [Twine](https://twinery.org/).
Le jeu peu également être joué directement dans un navigateur en executant le fichier `index.html`

## Améliorations
-Le jeu gagnerait probablement à avoir une interface reprenant les codes visuelles d'un chatbot.
